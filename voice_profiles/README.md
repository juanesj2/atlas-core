# Perfiles de Voz (Biometría)

Guarda aquí los audios de referencia para cada usuario de la casa.
El sistema extraerá la "huella matemática" de estas voces y la comparará con el micrófono del salón.

## Instrucciones:
1. Graba un audio tuyo de unos 5 segundos hablando normal.
2. Guárdalo aquí con tu nombre en formato `.wav` (ejemplo: `juanes.wav`, `laura.wav`).
3. El sistema reconocerá ese nombre automáticamente.
